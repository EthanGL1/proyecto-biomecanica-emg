## Aprendizaje automático y límites de interpretación

- **Cerqueira:** autorreporte ordinal de miembro superior (0/1/2), separado del estudio local de cuádriceps. El nested LOSO es evaluación interna por participante: análisis primario ≥90 % con 146 ensayos/44.886 ventanas y sensibilidad ≥95 % con 143/44.428. El macro-F1 medio por participante fue 0,368 (IC95 % 0,320–0,415) para EMG y 0,713 (0,666–0,755) para el diagnóstico temporal/de tarea. Este diagnóstico es distinto del predictor EMG; no se recomienda un modelo EMG para despliegue.
- Un proceso Python limpio reprodujo una inferencia de pliegue retenido desde señal cruda: 281.814 muestras, 223 ventanas completas de 1 s, aproximadamente 1.259,26 Hz, cuatro canales y 222 ventanas estables cotejadas con OOF (diferencia máxima de probabilidad 6,65×10⁻¹²). La salida de la señal completa y la salida reensamblada desde tres fragmentos cronológicos contiguos coincidieron exactamente. El recibo privado se identifica por SHA-256 a5643640397d9715d27bcde5810b515b73476eb9ec2297cb66f7a4d42f990562; no se incluyen señales ni predicciones individuales. Es reproducción interna del mismo corpus, no validación externa ni detección de fatiga funcional o de cuádriceps.
- El control temporal/de tarea es un diagnóstico separado y requiere posición dentro de la duración completa; no representa rendimiento EMG ni una herramienta online.
- **Borg de hombro:** el checkpoint no produjo probabilidad reproducible; Windows Application Control bloqueó la extensión nativa SciPy antes de la predicción. No se publica el checkpoint.

## Reproducibilidad y estado de entrega

El adaptador de `--input` acepta el esquema canónico `series,time_s,adc_value` o el esquema de origen `Relative_Time_s,ADC_Value[,Voltage_mV]`; este último requiere `--series R1–R5` explícito y no infiere etiquetas desde el nombre. `Voltage_mV` se ignora, sin asumir calibración. Los fragmentos se procesan por el modo agrupado con tiempos originales y claves explícitas; `--input` es para un único archivo.

La verificación fresca desde el runtime Python incluido por Codex terminó con 82/82 pruebas, `compileall` sin errores, ayuda CLI correcta y demo sintética completa (10 tramos, 200 ventanas, visor exportado). El adaptador de esquema crudo procesó un CSV completo. En una prueba separada, la interfaz `--cohort-fragments` reensambló CSV agrupados con claves explícitas y produjo siete tablas idénticas y el mismo dashboard que la entrada agrupada completa; esto no prueba que `--input --series` acepte fragmentos. Los 36 productos generados comprobados coinciden con sus SHA-256. Una copia temporal derivada usada como entrada ya no está en Temp; el ZIP fuente original sigue disponible y su SHA-256 coincide con el recibo. El E2E es descriptivo y no carga ni ejecuta un clasificador.
